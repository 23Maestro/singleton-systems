# Service Builds

Use the [website guide](../../docs/website/README.md) for Website Growth source
links, brand, SEO and form rules. Keep website code in its current folders.

Use a named project for a distinct technical build that helps editing or consulting.
Link the build and its Asana outcome both ways.

| Build | Project |
| --- | --- |
| Offer pages, technical SEO and website changes | [Website Growth](https://linear.app/23maestro/project/website-growth-f7ea9c80363d) |
| Review and delivery software | [Video Review](https://linear.app/23maestro/project/video-review-9109554210ff) |
| FaithTalk tools | FaithTalk TV |
| Lineups tools | Catena Media |

Use the matching Asana Lane for edits, posts, keyword research and client follow-ups.
A reusable content tool can need a build ticket. No separate Content Tools project
has been created yet. Reuse the closest existing project while its scope fits.

Closing the build does not prove client delivery. Keep each finish check separate.
