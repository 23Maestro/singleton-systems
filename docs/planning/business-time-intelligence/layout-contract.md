# Business Time Intelligence layout contract

Approved October 4, 2026. Jerami selected the actual TimeScribe interface as the foundation. This replaces the earlier six-region Glaze requirement.

Keep the TimeScribe sidebar, typography, project sheets and spacing. Overview: Day, Week, Month and Year. Keep Projects and App Activities. App activity uses native icons and two-column progress bars. Clock times use 12-hour notation.

Hide calendar, work schedules, leave and import/export. No filler subtitles or architecture callouts. No grid of repeated economics cards.

New project starts with Client work / Personal radio buttons before the name. Personal projects ask only for a name and optional appearance. Hide client, price, costs, fees, overhead and labor value. Keep tracked time and work logs in project details and period overviews. Do not invoke the Financial Engine for personal projects. A type change preserves earlier financial history without displaying it on a personal project.

Client project details show revenue, direct costs including fees, gross profit, margin, actual hours and profit/hour. Show overhead and operating profit when overhead is entered. Show labor target and economic profit separately with a short explanation using the project’s numbers. Financial values come from the Swift engine.

Verify the actual NativePHP desktop window, dragging, narrow widths and saved-record readback. Reference sources: `23Maestro/TimeScribe` at upstream `15c067e0336abd35b5eefd70a386016f437c7f30`. Earlier `standard-ui.jpeg` stays as reference history.
