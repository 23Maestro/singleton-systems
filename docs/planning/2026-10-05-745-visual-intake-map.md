## Glossary

- Visual contract: machine-readable treatment and fixed fields for a client lane.
- Reference lane: a supplied treatment, whether or not this batch contains a source for it.
- Intake map: persistent visual navigation into the contracts, assets and task tracker.
- Measured baseline: geometry from a reviewed sample, needed before applying relative ±10% adjustments.
- Inspiration: someone else’s supplied reference image, not a client source or completed template.
- Spatial zone: a cluster separated by canvas space; it need not have an enclosing background.
- Content-fitted card: a card whose height follows the rendered text and a recorded bottom padding.
