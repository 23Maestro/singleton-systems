## What belongs here

Keep reusable website decisions and their source links here. Each Lane's
[operations files](../operations/README.md) own its offer, audience, growth and
outreach rules. Link those facts; keep one copy. Website code stays in `app/`,
`components/` and `lib/`. Approved assets stay in `public/brand/`.

Put a page-specific decision in its Lane folder. Put a shared website rule at
this level. Keep work plans, blockers and closeout in the task tracker.
Dated research in [offer sources](../offer/README.md) is evidence, not a current offer.

## Who owns the work

Copy, SEO research and content outcomes stay in the matching Asana Lane.
Technical website changes belong to **Website Growth** under Service Builds.
Shared routing or dashboard plumbing belongs to **Internal Systems** under
Singleton Operations. Use the [project index](../../development/README.md).
Link a distinct build to the service outcome it supports.

A saved source file does not prove a live page, form delivery or search result.
Check each changed surface before calling it done.
