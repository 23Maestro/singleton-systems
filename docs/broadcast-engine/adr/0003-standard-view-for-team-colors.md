# Standard view for team colors

Broadcast frames use Blender's Standard view transform, or Khronos PBR
Neutral for lit logos. AgX is Blender's default and the installed skill
pack's rule, but it desaturates bright colors, so registered team hex values
come out wrong. Photographic looks lose some highlight roll-off under
Standard. Team color accuracy matters more for this client. A proof-frame
color readback enforces the rule.
