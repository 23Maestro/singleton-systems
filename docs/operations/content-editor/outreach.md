# Editing outreach

Use the shared [client card and follow-up rules](../clients-and-outreach.md).

Match the pitch to the footage, style and delivery the client needs. Use a relevant
edit, referral or approved sample. Ask for one clear next step.

Start with current clients and referrals, then returning clients and new prospects.
Keep seasonal follow-ups tied to real season dates. Do not treat a past client
as a cold lead.

The [outreach sheet](https://docs.google.com/spreadsheets/d/1RI6OGmv9HF5NTmHJu4Vk6QInT3Fs5-lOeXUZPTp8y28/edit)
keeps history. Asana holds the next action. Both must link to the same Supabase
client or prospect once the [record move](clients.md) is complete.

Use the existing Outreach and Gift skills. Gmail supplies message facts. Read
later replies before drafting. Sending needs approval for the actual message.
Do not create a second outreach ledger.
