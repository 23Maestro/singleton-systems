# Product ads

Build a rolodex of product spec ads for Upwork and the site. A real product moves on
screen and sells itself: drinks, snacks and apps.

First piece: poppi Cranberry Fizz spec, 15 s, 9:16. v4 uses a can built in Blender.

## How to show spec ads safely

This is common practice, not legal advice. Get a lawyer if a brand writes to you.

1. **Make the product yourself.** Build it with the [can template](../../../../tools/spec_ad/can_template.py)
   and a label redrawn from any internet photo. Never put the brand's own photo in the frame.
   Openly licensed photos from Wikimedia Commons can go in with a 1-line credit.
2. **Label every place it shows.** Keep "Spec ad. Not affiliated with poppi." on the end card.
   On Upwork, write "Mock ad for portfolio purposes. Not made for or approved by poppi."
3. **Keep it in the portfolio.** Show it on the site, in pitches and in organic posts.
   Never run it as a paid ad, a boosted post or an offer graphic.
4. **Never call the brand a client.** Keep spec work in its own section, apart from client work.
5. **Use only cleared sound.** Use CC0 or free-license tracks. Keep `assets/CREDITS.md` with every piece.
6. **Take it down fast.** If the brand asks, remove it the same day and reply politely.

## Where it is written

- poppi site terms (PepsiCo): site content is for "personal and non-commercial use".
  Derivative works from it are "expressly prohibited". https://contact.pepsico.com/poppi/terms-conditions
- Upwork IP rules: "Do not duplicate code, designs, or branded content without permission."
  A brand can file a DMCA notice, and Upwork can remove the item.
  https://support.upwork.com/hc/en-us/articles/39367506376339
- No written portfolio exception exists. Fair use is decided case by case after a dispute.

## How to make the next one

1. Redraw the flat label in code. The poppi example is [label_poppi.py](../../../../tools/spec_ad/label_poppi.py).
2. Run the can template with that label. It renders a cut-out can PNG.
3. Use the can in the scene. Software ads use a screen recording of the app.

## Where it goes on the site

The site has no video portfolio page yet. The video offer lives at `/video-inquiry`.

- Option A: a "Spec work" section on the home page with 1 to 3 videos, each labeled.
- Option B: a new `/product-ads` page with the videos, the label and a link to `/video-inquiry`.

Pick 1 before any site build.
