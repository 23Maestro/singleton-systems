# Triage labels

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Jerami needs to evaluate the issue |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-build` | Fully specified and ready for an approved build session |
| `ready-for-human` | `ready-for-human` | Requires direct human action |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill uses a canonical role, apply the corresponding Linear label.
Labels describe readiness only. They never trigger automatic work.
