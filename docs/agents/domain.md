# Domain docs

Before exploring the repository, read:

- `CONTEXT.md` for the shared Gate vocabulary.
- `CONTEXT-MAP.md` when present.
- Relevant decisions under `docs/adr/` when present.
- Context-specific decisions under `src/<context>/docs/adr/` when present.

Proceed silently when an optional file does not exist.

Use terms exactly as defined in `CONTEXT.md`. Do not replace `Lane` with
`Bucket` in front-facing language. `Bucket` remains an accepted trigger word
and tool-harness destination.

If work conflicts with an existing decision record, state the conflict before
proposing a change.
