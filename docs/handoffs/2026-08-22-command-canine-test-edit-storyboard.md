## Reference rules

- Keep the speaker on screen long enough to carry trust.
- Use black, white, gray, and a sampled reference blue.
- Use large uppercase labels and short supporting lines.
- Use direct slides, fades, and modest scale changes. No bounce or playful icon motion.
- Add one quiet sound accent per graphic change. Keep the music bed restrained.
- Use B-roll to explain a claim or hide a source edit.

## Delivery envelope

- 1920×1080, 16:9, 24 fps.
- Target runtime: 48–52 seconds.
- Selective on-screen text. No full burned captions for this test.
- H.264 review MP4 with 48 kHz stereo audio.
- HyperFrames owns the five designed motion beats. Premiere owns dialogue,
  pacing, color, sound, assembly, and export.
