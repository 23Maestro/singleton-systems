# Lineups Topic Builder

Selection-first Figma plugin for building Lineups topic scenes from locked broadcast components.

## v1 contract

Select:

- One Lineups component instance
- One to four image layers containing transparent athlete PNGs

Enter a headline and choose **Generate scene**. The plugin:

1. Clones the selected Lineups instance.
2. Sets its player-count variant when available.
3. Sets its headline property.
4. Maps selected image layers from left to right into named player slots.
5. Places the new scene to the right of the source instance.

The plugin does not draw or alter source geometry.

## Figma component contract

The approved page-6 component family exposes:

```text
Headline       TEXT
Players        VARIANT: 1, 2, 3, 4
```

Supported player slot names include the approved nested instances:

```text
LINEUPS_SLOT_Player_1
LINEUPS_SLOT_Player_2
LINEUPS_SLOT_Player_3
LINEUPS_SLOT_Player_4
PLAYER_1
PLAYER_2
PLAYER_3
PLAYER_4
```

Directional atom names are also supported:

```text
LINEUPS_ATOM_PlayerCutout_Left
LINEUPS_ATOM_PlayerCutout_CenterLeft
LINEUPS_ATOM_PlayerCutout_Center
LINEUPS_ATOM_PlayerCutout_CenterRight
LINEUPS_ATOM_PlayerCutout_Right
```

Each slot must contain an image-fill layer. The plugin replaces that nested image while preserving the slot's 120×126 bounds, crop, overlap, and edge masking.

## Local development

```bash
npm install
npm run verify
```

In the Figma desktop app:

1. Open **Plugins → Development → Import plugin from manifest**.
2. Select this folder's `manifest.json`.
3. Run **Lineups Topic Builder** from the Development menu.

Replace the placeholder manifest `id` with the development ID generated by Figma before publishing.
