Architecture decision still open. This replaces Glaze/React and divides persistence between business records and raw activity. The existing Linear contract says Glaze plus one Swift-owned store. Accept this change before implementation or rewriting ticket acceptance criteria.
Ownership and failure rules
  • Only the Swift agent writes raw activity. Laravel opens it read-only.
  • Only Laravel writes business records; project assignments reference immutable raw-event IDs.
  • Separate databases have no cross-database foreign keys. Reprocessing, retention and stable-ID checks need public contract tests.
  • Recording continues when the desktop quits; next launch imports/reclassifies pending context. A durable native login agent is still required.
  • Time totals use accepted interval union. Reports and practice never calculate their own profit or fees.
  • Disable upstream crash/usage telemetry and update network calls by default. This must be checked in the packaged build.
  • Alternative: retain Glaze/Swift and extract patterns. That requires porting Vue/PHP and saves less of the complete app.
