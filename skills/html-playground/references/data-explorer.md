# Data Explorer Lane

Use for SQL, APIs, pipelines, regex, schedules, or structured configuration.

- Controls: source and field choices, repeatable filters, grouping, ordering,
  and a bounded result limit.
- Preview: render syntax-highlighted output or a small pipeline diagram.
- Prompt: specify the requested behavior and schema context rather than merely
  copying the generated query.
- Presets: represent real query intents such as Overview, Errors, Recent, or
  Aggregated.

Escape user-provided values before inserting them into preview HTML. Make empty
and invalid states explicit without breaking the useful default.
