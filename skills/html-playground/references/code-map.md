# Code Map Lane

Use for architecture, components, data flow, services, or plugin relationships.

- Prefer SVG for nodes, labeled connections, zoom, and filtering.
- Group nodes into a few real layers and distinguish connection types with both
  color and line style.
- Let the reviewer focus layers and comment on a component.
- Prompt output should name the component, real file path, and reviewer note.
- Pre-populate only verified components and relationships. Mark uncertainty.

For a human review surface, keep 5-9 meaningful nodes and short edge labels.
Use a larger map only when the user explicitly needs architecture inventory.
