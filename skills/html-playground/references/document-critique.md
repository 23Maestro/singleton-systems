# Document Critique Lane

Use for reviewing a skill, README, spec, proposal, or other document.

- Show the document or selected excerpts with stable line references.
- Present suggestions as Pending, Approved, Rejected, or Commented.
- Let the reviewer filter statuses and attach a note to a suggestion.
- Generate prompt output only from approved changes and explicit reviewer notes.
- Preserve rejected suggestions as local review context, not implementation
  instructions.

Pre-populate specific, actionable suggestions. Do not bury the main review
question under a full document inventory.
