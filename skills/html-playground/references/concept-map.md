# Concept Map Lane

Use for learning, scope mapping, knowledge gaps, relationships, or dependent
tasks.

- Let the visual act as a control: select, move, focus, or connect nodes.
- Keep the initial map to 5-9 meaningful nodes for a review surface; expand only
  when the task requires deeper exploration.
- Mark knowledge as known, fuzzy, or unknown and relationships with short verbs.
- Prompt output should ask for help with fuzzy or unknown areas while building
  on what is already understood.
- If using canvas or SVG, draw edges before nodes, provide keyboard-accessible
  alternatives, and keep labels readable at the default zoom.

Never replace real task state with the visualization.
