# Diff Review Lane

Use for commits, pull requests, or before-and-after code changes.

- Group changed lines by file and hunk with stable old/new line numbers.
- Color additions, deletions, and context distinctly in both light and dark
  modes.
- Let the reviewer comment on a line and edit or remove that comment.
- Prompt output should include file, line, relevant code, and reviewer comment.
- Start with changed files collapsed or filtered when the diff is large.

Never embed secrets or unrelated working-tree content in the HTML artifact.
