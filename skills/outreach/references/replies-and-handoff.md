# Replies and handoff

Read the full original reply before choosing a class. Preserve it for review.
A human reply stops the remaining cold sequence. Coordinate other outreach to
the account. Keep the offer and promises with the same opportunity owner.

| Reply | Next step |
| --- | --- |
| Relevant affirmative interest | Stop cold touches; route the actual request |
| Clear decline | Close this opportunity; no automatic recycling |
| Opt-out | Suppress across campaigns and enabled channels |
| Timing request | Stop cold touches; honor the requested date |
| Referral | Check the referred role and exact introduction permission |
| Source or address question | Answer with the recorded source facts |
| Delivery error | Suppress invalid addresses; route setup errors for repair |
| Unclear intent | Hold for human review |
| Automatic absence | Pause; use the date guide's return rules |

An interested reply is a relevant affirmative human response to the offer.
A request for the offered sample, information, price or meeting can qualify.
Count each interested person once per cohort. A meeting is not required.
Exclude automatic replies, courtesy thanks, declines and source questions alone.
Keep timing requests and referrals visible; count interest only when supported.

Deliver the promised asset without a hidden booking condition. Record owner,
inputs, preparation state and delivery time. Escalate unsupported claims or new
commitments. R&H ends at reply classification and handoff; sales-stage actions
and post-reply waits in this harness are our adaptations.

For handoff, keep account, person, role, time zone, source, full thread, offer,
CTA, exact request, prior proof, claims, assets, unresolved questions and next
step. Confirm that the receiving owner can access them. Keep handoff timing
and backup coverage in the accepted campaign brief.

Measure unique accounts, contacted people and total sends separately. Report
human reply rate and interested reply rate per unique contacted person. Keep
meetings, wins, bounces and opt-outs separate. No interested replies means PCPL
has no finite observed value, not zero. Attach late replies to their cohort.
Check delivery and data before blaming copy. Opens provide limited evidence.
