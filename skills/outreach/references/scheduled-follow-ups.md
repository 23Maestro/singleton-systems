# Scheduled follow-ups

## Scope

On November 17, 2026, Jerami authorized automatic unsent drafts and due-day
notices. Use the existing weekday check at 9:00 AM America/New_York. Its accepted
Asana actions and linked outreach rows define enrollment. Do not enroll every
old prospect. Preserve excluded contacts, holds, user edits and accepted dates.
This workflow never sends or schedules a send.

Use this guide for the method, message patterns and dates. Alex strategy is
optional supporting research. Do not hold a valid action solely because its
plugin is absent. Source gaps in a proposed claim still require a hold.

## Each run

1. Read accepted Asana actions and their linked rows. Include future review
   dates so accepted drafts can be prepared ahead of time. Check the current
   Lane and offer. Do not reopen a parked lead without an accepted plan.
2. Read full Gmail history across subjects, later replies, errors, opt-outs
   and drafts. Count real sends once by message ID. If history fails, hold the
   lead. A human reply cancels the pending cold nudge.
3. Run the date helper from the skill's real folder. Use the actual event,
   recipient calendar and full counts. Promised dates win. Keep old overdue
   dates. An accepted later follow-up plan must match the observed send count.
4. For a permitted message action, prepare 1 unsent in-thread draft. Search
   matching drafts first. Reuse the match. Preserve user edits. Report conflicts
   instead of overwriting them. Never claim unfinished sample work is ready.
5. Read back exact recipient, body, thread, draft ID and DRAFT label. Keep
   source and draft IDs in the same accepted Asana action. Update only the
   matched sheet row after a current read. Preserve history and formulas.
6. On or after the review date, recheck Gmail and the saved draft. Only then
   post a ready notice with due date and the exact thread or task link. Key
   notices by source message, draft and due date in the accepted action. Read
   the target chat when available to avoid duplicate notices after a partial
   write. If notice state is uncertain, reconcile it before repeating a notice.

A deleted draft stays held. Report it once when due; do not silently recreate
it. Preserve a stale draft after a reply until Jerami chooses its treatment.
Do not say ready after a failed draft read. Report a due-day blocker once and
retry only the missing operation on a later run. Missing sheet access may leave
sync pending for an accepted action with verified Gmail and dates.

After an actual send, verify SENT before logging it or advancing the plan.
Recompute from full exposure. An exhausted sequence gets internal review; only
a newly accepted plan can select another follow-up. A draft never starts a timer.
Stay quiet before due day or when no new due action or blocker needs attention.

Reuse `prepare-outreach-follow-ups` in the native automation folder. Its local
file proves saved settings, not execution, a delivered notice or a phone push.
Do not create 1 recurring schedule per contact. Keep enrollment facts in their
existing records; this guide is not a second lead list.
