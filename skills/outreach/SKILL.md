# Outreach

Give each chosen opportunity 1 useful next step and a date. Show Jerami a
short `Who | Next step | When` list. This folder owns the shared method.
Gift is a small entry point to this guide.

## Start with the facts

Read the workspace guide and the Lane's current offer.

Use each record for its job:

- **Workspace guide:** business facts.
- **Gmail:** sent mail and replies.
- **Outreach sheet:** contact history.
- **Asana:** the approved next step.
- **Supabase:** client records, under the guide's current rules.

Keep the same record IDs.

Before planning contact, read all related Gmail threads. Count each sent email
once by its message ID. Skip drafts and old emails quoted in replies.

Check replies, requests to stop, declines, away messages and failed sends first.
A new subject does not erase past sends. If history is missing, pause and check it.

Pick an offer and 1 clear ask that fit the buyer's goal and the conversation.
A sample or a direct service offer can work. Use facts you checked.
Say work is done only when it is.

For dates, find this skill's real folder and run `scripts/next_action.py`.
Read the date guide for its JSON inputs. It plans review dates and cannot use
connected apps.

## Stay within the ask

Draft when asked. Save a draft when asked or through the approved follow-up check.

Send only when Jerami approves that message or batch. Dates, drafts and guides
do not give permission to send.

Update only the chosen opportunity. Keep user edits, formulas, history and
other offers at the same company. Read each saved change back.

If a send is unclear, check Gmail before trying again. Never resend just to fix
a record.

A short email run can end without ruling out later contact. Check the history,
choose a useful reason and agree on the next step. Time passing alone does not
add someone to automatic follow-ups.
