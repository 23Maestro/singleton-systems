# Agency growth

Load `$outreach` for the shared method. It owns buyer fit, source checks,
entry offers, messages, follow-ups, reply handling and dates. Gift opens its
sample guidance. If Outreach is unavailable, report the missing owner and
hold the action; do not rebuild a second playbook here.

Read the matching Lane's current business facts through the active workspace
operating guide. Choose 1 useful output for the request: account brief, offer,
message or next action. A verified company event can help timing; a durable
buyer problem can also support the offer. Keep assumptions clear.

Use `freelance-gig-proposals` for a marketplace post and
`offer-portfolio-content` for portfolio social content.

Gmail owns actual message events. The existing outreach row holds history;
Asana owns the accepted next action. Follow the workspace client-record rules.
Preserve IDs and user edits. Drafting and sending have separate gates.
Run the Final Human Pass before showing final copy. Never automate sends.
