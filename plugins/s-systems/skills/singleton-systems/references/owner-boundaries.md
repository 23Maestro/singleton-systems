# Owner Boundaries

## Durable Owners

```text
unselected thought       -> Linear Command + Ideas
active system plan       -> Linear Singleton Systems
fuzzy multi-session work -> Linear Wayfinder map
runtime/dashboard fact   -> Supabase
career workflow state    -> Opportunity HQ
portfolio or client asset    -> Eagle
desktop/mobile action    -> Raycast or Shortcuts
active-week review       -> Next/Vercel
reviewed architecture    -> LikeC4
```

Do not copy task state into dashboards, full ticket text into Supabase, or
portfolio assets into planning systems. The dashboard reads owner state and opens
owner links.

Before changing an owner boundary, state the owner, intent, smallest tool
stack, review gate, verification command or readback, and what must not be duplicated.
Keep credentials server-side. Prefer the narrow owning skill when one exists.
