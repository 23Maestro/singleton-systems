# Proposal Contract

## Inputs

Use the actual post, platform, rate or budget, requested deliverables, timeline,
and any provided screening questions. Separate verified facts from inference.

## Shape

1. Open with one useful question tied to the work.
2. Give one or two truthful proof anchors that answer the client's risk.
3. Connect adjacent experience plainly when the exact example is unavailable.
4. End with one easy next step.

Keep the proposal short, specific, and human. Do not restate the post, list
generic skills, invent results, or imply an application was sent. When asked
for variants, return question-first, warmer, and direct versions under 500
characters unless the platform requires another limit.

Run a Final Human Pass before showing the copy as final or sending it.
