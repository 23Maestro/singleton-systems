# Resume Workflow

## Source of Truth

Start with the canonical Reactive Resume JSON. Treat exported PDFs and tailored
documents as generated outputs. Never invent employers, dates, tools, metrics,
credentials, education, or remote eligibility.

## Job-Specific Pass

1. Read the actual post and capture title, employer, location, compensation,
   schedule, required qualifications, application questions, and constraints.
2. Separate requirements into verified match, adjacent evidence, and proof gap.
3. Tailor the summary, skills, and only the most relevant bullets.
4. Preserve truthful scope and seniority. Do not keyword-stuff.
5. Surface paywalls, subscriptions, vehicle requirements, location limits, and
   unclear remote claims before application.

Use a clean single-column document when Reactive Resume is unavailable. If an
export is requested, extract its text and visually inspect the PDF for clipping,
spacing, hierarchy, links, and page breaks before calling it ready.

For full applications return the angle, summary, bullet swaps, keywords,
required details, and proof gaps. For quick asks return only the highest-impact
edits. Use `references/application-detail-ledger.md` for repeated form fields or
upload conflicts.
